# Стиль коммитов

История проекта — короткие русские заголовки в императиве, без префиксов
(`Показывать архив выступлений из Notion на сайте`, `Не начислять рейтинг за
техническую победу`). Держаться этого же стиля, а не conventional commits.

## Заголовок

- До ~72 символов, с заглавной буквы, без точки в конце.
- Что изменилось для пользователя или системы, а не «правки», «фиксы», «update».
- Один коммит — одна причина. Если в теле хочется написать «а ещё» — это второй коммит.

## Тело

- Зачем изменение, а не пересказ дифа. 1–4 строки, пустая строка после заголовка.
- Если есть ограничение или компромисс (данных нет, осталось на потом) — сказать здесь.
- Хвост: `🤖 Generated with Codebuff` и `Co-Authored-By: Codebuff <noreply@codebuff.com>`.
  Не добавлять, если пользователь или инструкции проекта отказались от атрибуции.

## Что не коммитить

- `.dev.vars`, `.setup-token`, `.turnstile-secret` — секреты.
- `КНИГА УЧАЩИХСЯ.xlsx` — персональные данные воспитанников.
- `screenshots/`, `.tmp-*.log`, `.tmp-*.sql`, `dist/`, `worker-dist/`, `.wrangler/`.

## Порядок

1. `git status` и `git diff` — убедиться, что в коммит попадает только нужное.
2. `git add` конкретными путями, а не `git add -A`.
3. Коммит, затем `git log --oneline -3` для проверки.
4. Push — только по явной просьбе. Коммит и публикация — разные разрешения.
