# Ревью кода

Сначала прочитать диф целиком (`git diff`, `git diff --cached`), потом список ниже.
Замечания — по убыванию риска, без вкусовщины.

## Корректность

- Границы: пустой список, `null`, `0`, отсутствующая связь. В этом проекте уже был
  баг «— — Имя» при `place = null` — такие случаи проверять явно.
- Даты и часовые пояса: сравнение месяца и дня для дней рождения идёт со сдвигом UTC+3.
- Деньги/рейтинг: округление и порядок операций, откат итогов турнира.
- Дубли данных: импорт идемпотентен, повторный запуск не плодит строк.

## API и данные

- Изменения схемы ответа — вместе с типами в `src/lib/types.ts` и `src/lib/api.ts`.
- Публичное API отдаёт только разрешённые поля: имя, год рождения, разряд, места.
  Телефон, адрес, приказы, полная дата рождения — никогда.
- N+1 и лишние выборки: агрегация в SQL, а не в цикле по 4000 строк.

## Интерфейс

- Состояния: загрузка, пусто, ошибка. Пустое состояние объясняет, что произойдёт дальше,
  а не просто «Нет данных».
- Ссылки и кнопки: куда ведут, что произойдёт после нажатия, доступны ли с клавиатуры.
- Демо-записи: бейдж «Демо» и `noindex` не теряются при новых выборках.

## Безопасность и приватность

- Секреты только в окружении; в клиент не попадает ничего серверное.
- Мутации проверяют `Origin`, права — на сервере, а не в интерфейсе.
- SQL — только связанные параметры.

## Формат замечаний

`файл:строка — проблема — почему это важно — что сделать`. Отдельно: «блокирует» и
«можно позже». Если всё в порядке — так и сказать, без выдуманных придирок.
